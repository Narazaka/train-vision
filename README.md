# トレインビジョン ジェネレータ

VRChat 鉄道ワールド向けに、車内 LCD 案内表示風の画像を作って PNG で書き出すツール。

```
npm install
npm run dev      # 編集UIを開く
npm test         # 図形計算のテスト
npm run build    # dist/ に静的ファイルを出力（そのまま開ける）
```

左が編集UI、右がライブプレビュー。倍率を選んで「PNG保存」で高解像度 PNG が落ちる（既定 960×720 の ×8 で 7680×5760）。

## データの保管

編集中の内容もプリセットも、**ブラウザの localStorage にしか入っていない**。ブラウザのデータを消したり別のブラウザで開いたりすると失われる。

残しておきたいものは「JSON で読み書き」を開いて JSON をコピーし、ファイルに保存しておくこと。貼り戻せばそのまま復元できる（書かれていないキーは既定値で補われるので、`style` を省いた JSON でも読める）。

## プリセット

名前を付けて保存しておくと、種別・行き先・駅リスト・見た目まで含めて丸ごと切り替えられる。

- **保存**: 名前を入れて「保存」。同名なら上書き
- **読み込み**: 左のプルダウンから選ぶ。選んだ瞬間に切り替わり、名前欄にその名前が入る
- **削除**: 名前欄にその名前がある状態で「削除」
- **(既定値に戻す)**: プルダウンの一番上。保存済みプリセットは消えない

保存していない編集内容は読み込み・リセットで失われるので、使い回すものは先に保存しておく。

## 表示の決まり

| 設定 | 見た目 |
| --- | --- |
| 停（stop） | 駅名が黒、帯の印が白丸。OFF なら灰色＋白横棒（通過駅） |
| 省（gap） | その駅とひとつ前の駅の間で帯が S 字に切れる。駅番号を飛ばして表示するときに使う |
| 現（current） | 赤いマーカー。その駅の中心に置かれ、進行方向へ尖る。帯は手前で切れる |
| 進む向き（heading） | 帯の先端の尖りと外側の `<` 形、赤マーカーの向き |
| 左右反転（reverse） | ドア方向に合わせて路線図全体を鏡像にする。切れ目・現在位置も追随する |
| 後方にも路線が続く（tailOpen） | 帯の末端を進行方向と同じ向きに `<` と切り欠き、外に `<` を添える。OFF なら垂直に切り落とす |

## 走行中表示

「つぎは」を ON にするとヘッダーが2段になる。上段は種別＋白枠に入った行き先、下段は「つぎは ○○」と次駅の駅番号。黒地の高さは1段のときと変わらない。

「駅間を走行中」を ON にすると、現在位置が駅と駅のちょうど中間に入る。このとき

- 現在位置より後方の帯が灰色になる。前方側の切り口は赤マーカーの斜辺と平行な V 字、後方側は垂直で、間に `markerGap` ぶんの白い隙間が一定幅で残る
- 通り過ぎた駅は、停車駅であっても駅名・駅番号が灰色になる

OFF に戻せば元の停車中表示になる。最後の駅（その先に駅がない側）では ON にできない。

## 英語表記

編集UIの一番上、**「表記」で日本語／英字を切り替える**。切り替わるのは並べ方だけで、駅名や行き先の文字はそのまま残る（翻訳はしない）。

| | 日本語 | 英字 |
| --- | --- | --- |
| 駅名 | 1文字ずつ縦積み | 右上へ倒した1行書き（`nameAngle` = -60） |
| 接尾語 | 四日市 **ゆき**（後ろ） | **for** Yokkaichi（前） |
| 「つぎは」ラベル | つぎは | Next |

ラベルは既定の「つぎは」「Next」のままなら自動で入れ替わり、自分で書き換えていればそのまま残る。傾きの角度や起点は「見た目の調整 → 駅名」の `nameAngle` / `nameAngleX` で変えられる。

行き先・次駅・傾けた駅名は、**描画幅を実測して枠に収まるまで自動で縮む**ので、長い駅名を入れても駅番号バッジや種別バッジに食い込まない。欧文だけの行では全角用の字間（`destSpacing` / `nextSpacing`）を自動的に無視する。

「見た目の調整」を開くと、色・フォント・各部の座標とサイズをすべて数値で変えられる。

## 構成

```
src/types.ts        Vision / Station / Style の型
src/defaults.ts     既定値と、日英で入れ替わる設定
src/geometry.ts     帯・マーカー・駅名位置の計算（純関数。テスト対象）
src/geometry.test.ts
src/Vision.tsx      SVG の組み立て
src/Editor.tsx      編集UI
src/storage.ts      localStorage の読み書きと、欠けたキーの補完
src/storage.test.ts
src/png.ts          PNG 書き出し
```

帯の形（尖りの深さ、切り欠き、S 字の振れ幅、マーカーの寸法、各部の余白）は実機の表示画像をピクセル単位で計測して決めてある。`defaults.ts` の数値を動かすときは、`geometry.test.ts` が形の決まり（切れ目が左右反転で鏡像になる、隙間の幅が一定になる、など）を固定しているので、テストを通しながら調整するとよい。
